# متجر LAVÉRA — كتالوج ECOWAY

متجر إلكتروني ثابت (Static Site) بيعرض كل منتجات كتالوج ECOWAY (فوط ومايكروفايبر، Eco Touch، Coco Lab، عطور Ecoway) بالصور والأسعار الحقيقية، مع سلة مشتريات وطلب مباشر عبر واتساب، ولوحة إدارة بسيطة لتعديل المنتجات.

## هيكل المشروع

```
ecoway-store/
├── index.html              ← الصفحة الرئيسية
├── assets/
│   ├── css/style.css       ← تنسيقات إضافية بسيطة
│   ├── js/app.js           ← كل منطق المتجر (سلة، فلترة، لوحة إدارة)
│   └── img/                ← صور المنتجات (56 صورة من الكتالوج الأصلي)
├── data/
│   └── products.js         ← بيانات المنتجات (الاسم، السعر، الوصف، رابط الصورة...)
└── README.md
```

## طريقة رفع المتجر على GitHub Pages (خطوة بخطوة)

### 1. أنشئ مستودع (Repository) جديد
- ادخل على [github.com](https://github.com) وسجّل دخول.
- اضغط **New repository**.
- اختار اسم زي `ecoway-store` (أي اسم تحبه).
- خليه **Public**.
- **متعملش** تفعيل "Add a README file" لو هترفع الملفات دي كلها بنفسك.
- اضغط **Create repository**.

### 2. ارفع ملفات المتجر
**الطريقة الأسهل (من المتصفح مباشرة):**
- في صفحة المستودع، اضغط **uploading an existing file**.
- اسحب مجلد `ecoway-store` بالكامل (أو كل الملفات والمجلدات جوه بعضها) وارفعها.
- تأكد إن الترتيب فضل زي ما هو (`assets/`, `data/`, `index.html`).
- اكتب رسالة commit زي "رفع المتجر" واضغط **Commit changes**.

**أو باستخدام Git من التيرمينال:**
```bash
cd ecoway-store
git init
git add .
git commit -m "رفع متجر LAVÉRA - كتالوج ECOWAY"
git branch -M main
git remote add origin https://github.com/USERNAME/ecoway-store.git
git push -u origin main
```
(غيّر `USERNAME` باسم حسابك على GitHub)

### 3. فعّل GitHub Pages
- روح لـ **Settings** في المستودع.
- من القائمة الجانبية اختار **Pages**.
- تحت **Build and deployment** → **Source**، اختار **Deploy from a branch**.
- اختار **Branch: main** و **Folder: / (root)**.
- اضغط **Save**.
- استنى دقيقة أو اتنين، وهيظهرلك لينك المتجر تحت في نفس الصفحة، شكله كده:
  ```
  https://USERNAME.github.io/ecoway-store/
  ```

المتجر هيفضل شغال ومجاني 100% على GitHub Pages، وأي تحديث في الملفات وترفعه (push) هيتحدث تلقائياً على نفس اللينك.

## إزاي تعدّل المنتجات؟

في طريقتين:

**1. من لوحة الإدارة داخل الموقع نفسه:**
- افتح المتجر واضغط "لوحة الإدارة" في الهيدر.
- كلمة السر الافتراضية: `1234` (غيّرها فوراً من نفس اللوحة).
- تقدر تضيف/تعدل/تحذف أي منتج مباشرة من المتصفح.
- ⚠️ **مهم:** التعديلات دي بتتخزن في متصفح الزائر نفسه (localStorage)، يعني كل شخص بيفتح الموقع من جهازه هيشوف نسخة الكتالوج الأساسية، والتعديلات اللي عملتها من جهازك تفضل عندك بس. مفيش قاعدة بيانات مركزية لإن الموقع Static (بدون سيرفر).

**2. من ملف `data/products.js` مباشرة (الطريقة الدائمة والموصى بها):**
- افتح الملف وعدّل بيانات أي منتج (الاسم، السعر، الوصف، `img`...).
- ارفع (commit + push) التعديل على GitHub، وهيظهر لكل الزوار تلقائياً بعد نشر Pages (دقيقة أو اتنين).

## طلبات الشراء

الطلبات بتتبعت مباشرة كرسالة جاهزة على واتساب على الرقم:
```
01097753110
```
تقدر تغيّر الرقم من متغير `STORE_WHATSAPP` في أول ملف `assets/js/app.js`.

## ملاحظة عن كون المتجر "Static"

الموقع مبني بالكامل بـ HTML/CSS/JS بدون أي سيرفر أو قاعدة بيانات، وده يخليه:
- ✅ مجاني تماماً على GitHub Pages
- ✅ سريع جداً وآمن
- ❌ مفيهوش نظام دفع إلكتروني حقيقي أو تتبع مخزون مركزي — الطلب بيتم تأكيده يدوياً عبر واتساب، وهي نفس الطريقة المستخدمة حالياً.

لو حبيت مستقبلاً تضيف نظام دفع أونلاين حقيقي أو قاعدة بيانات مركزية للطلبات والمخزون، محتاج وقتها منصة فيها Backend (زي Shopify، أو موقع مبني بـ Node.js/Firebase) بدل GitHub Pages وحدها.
